# Ayeixa FuelLite

> Zero-cost multi-provider token arbitrage and failover router supporting Gemini, Groq, Cerebras, and Chutes.

## Overview
Ayeixa FuelLite is an open-source component developed under the Ayeixa Public-Good Flywheel.
It provides modular, high-reliability infrastructure licensed under permissive **MIT**.

## Quick Start

```bash
npm install @ayeixa/fuellite
```
